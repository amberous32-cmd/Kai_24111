# khweather

Консольная утилита для вывода текущей погоды в указанном городе.
Работает через [wttr.in](https://wttr.in) — без API-ключей и регистрации.

## Что показывает

- температуру,
- ощущаемую температуру,
- скорость ветра,
- краткое описание погоды.

## Требования

- Python 3.8+
- библиотека `requests`

Установить `requests`:

```bash
pip install requests
```

## Установка

Скачай репозиторий и запусти установщик из его папки.

**Linux / macOS:**

```bash
chmod +x install.sh
./install.sh
```

**Windows:**

Запусти `install.bat` от имени администратора (правый клик → «Запуск от имени администратора»).

## Использование

```bash
kh_weather Москва
```

Пример вывода:

```
Погода в Москва:
  Температура: 5.2°C
  Ощущается как: 2.1°C
  Ветер: 3.4 м/с
  Описание: переменная облачность
```

## Удаление

**Linux / macOS:**

```bash
sudo rm /usr/local/bin/kh_weather
```

**Windows:**

```bat
del C:\Windows\kh_weather.py
del C:\Windows\kh_weather.bat
```

## Как это работает

1. Скрипт отправляет GET-запрос на `https://wttr.in/<город>` с параметром `format=j1`.
2. wttr.in возвращает JSON с текущей погодой.
3. Скрипт извлекает нужные поля и печатает их в терминал.

Если город не найден или сеть недоступна — выводится сообщение об ошибке.

## Ограничения

- Требуется доступ в интернет.
- wttr.in — публичный сервис, возможны задержки и временная недоступность.
- Название города лучше писать латиницей (`Moscow`), но русские названия тоже поддерживаются.
